# Available CLI Tools

The following tools are installed on the system and available on PATH:

## Data / Text Processing

- `jq` — JSON processor
- `yq` — YAML/JSON processor
- `yj` — YAML/TOML/JSON/HCL converter

## Development

- `gh` — GitHub CLI
- `rg` (ripgrep) — Fast grep
- `shellcheck` — Shell script linter

## Runtimes

- `go`, `gofmt`
- `node`, `npm`, `npx`
- `python3`, `pip3`

## Instructions

If a task would benefit from a common CLI tool not listed above, suggest that the user install it with Homebrew, WinGet or Apt.
