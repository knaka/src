# “Mise” — tool version and task manager

mise manages project-local tool versions and runs tasks. Tool versions are listed in `.mise.toml` and `.mise/conf.d/*.toml`.

mise can be invoked without a global installation using the bootstrap scripts: `./mise` on Linux and macOS, or `.\mise.cmd` on Windows.

````bash
# install all tools
./mise install

# execute a project-locally-installed command
./mise exec -- jq --help

# list available tasks
./mise tasks

# run task `foo`
./mise run foo

# show a task `foo`'s full description and the path of the file that defines it
./mise tasks foo
````

## File layout

Files for mise work behind the scenes, so they are dotfiles that `ls` does not show. Only the bootstrap scripts, which users type, are visible.

| Path | Role |
|---|---|
| `./mise`, `.\mise.cmd` | Bootstrap scripts |
| `.mise.toml` | Main configuration: settings, environment variables, and tool versions |
| `.mise-tasks.sh`, `.mise-tasks.bash` | The project's main function tasks |
| `.mise/conf.d/*.toml` | Shared configuration, read together with `.mise.toml` |
| `.mise/tasks-*.sh`, `.mise/tasks-*.bash` | Shared function tasks |
| `.mise/tasks/` | File tasks: one executable file per task |
| `.mise/conf.d/_function-task-bindings.toml` | Generated by the `funcs:bind` task. Do not edit |

Project-specific files go at the top of the project. Files shared across tasks or projects go under `.mise/`.

## Function tasks

A function task is a task defined as a shell function in a file that holds several of them, such as `.mise-tasks.{sh,bash}` or `.mise/tasks-*.{sh,bash}`.

* A function named `task_<name>` defines the task `<name>`. `__` in the function name becomes `:` in the task name, so `task_docker__start` defines `docker:start`.
* The comment line directly above the function becomes the task's description.
* `#MISE` lines above the function add task settings, such as `#MISE tools={"uv"="0.10"}`.

mise does not read these files directly. The `funcs:bind` task generates `.mise/conf.d/_function-task-bindings.toml`, which defines one TOML task per function that sources the file and calls the function. After adding, removing, or renaming a function task, or changing its comment or `#MISE` lines, run `funcs:bind` in that project's directory and commit the regenerated file.

````bash
./mise run funcs:bind
````

If the generated file is broken and mise cannot load its configuration, run the script directly, without mise, to regenerate it.

````bash
sh .mise/tasks/funcs/bind.sh
````
